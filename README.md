# پنل مدیریت Xray-core (مشابه 3x-ui / Sanaei Panel)

یک پنل مدیریت قدرتمند، امن و مدرن برای سرویس‌های Xray-core با پشتیبانی کامل از پروتکل‌های VMess، VLESS (با XTLS-Reality)، Trojan و Shadowsocks، مدیریت ترافیک، ساخت لینک‌های اشتراک (Subscription)، ربات اطلاع‌رسانی و احراز هویت امن.

---

## ویژگی‌های اصلی

- **پشتیبانی کامل از پروتکل‌ها:** VMess، VLESS (با XTLS-Reality)، Trojan و Shadowsocks.
- **ترنسپورت‌های متنوع:** TCP، WebSocket، gRPC، HTTP/2، mKCP.
- **مدیریت پیشرفته کلاینت‌ها:** تعیین سقف حجم، تاریخ انقضا، تعداد دستگاه همزمان (IP Limit)، و ریست ترافیک.
- **لینک اشتراک (Subscription):** لینک اختصاصی Base64 برای کلاینت‌ها جهت اتصال خودکار به تمام اپلیکیشن‌ها.
- **امنیت بالا:** احراز هویت با JWT، هش پسورد با bcrypt، قفل هوشمند ضد Brute-Force و پشتیبانی از 2FA.
- **داشبورد و آمار لحظه‌ای:** نمایش وضعیت CPU، RAM، دیسک، آپتایم و ترافیک مصرفی.
- **اسکریپت نصب خودکار:** نصب و راه‌اندازی آسان روی توزیع‌های مختلف لینوکس با یک دستور.

---

## ساختار پروژه

```
project-root/
├── app/                  # کدهای بک‌اند (FastAPI, SQLAlchemy, Auth, Xray Manager)
├── frontend/             # رابط کاربری وب (Vue 3 + Tailwind CSS)
├── systemd/              # فایل سرویس systemd
├── docker/               # Dockerfile و Docker Compose
├── scripts/              # اسکریپت نصب و حذف خودکار
└── README.md
```

---

## روش نصب سریع (تک خطی)

```bash
sudo bash scripts/install.sh
```

پس از اتمام نصب، پنل روی پورت `8000` در دسترس خواهد بود.

- **نام کاربری پیش‌فرض:** `admin`
- **کلمه عبور پیش‌فرض:** `admin123`

*(توصیه می‌شود پس از اولین ورود کلمه عبور را تغییر دهید).*

---

## اجرا با Docker Compose

```bash
cd docker
docker-compose up -d --build
```
